# High-Dimensional-Gaussian-and-Bootstrap-Approximations-in-GLM
This repository contains reproducible R code for the simulation studies and real data analysis for bootstrapping generalized linear models in high dimensions.

## Structure
- **simulations/**: Scripts for Regime I (moderate dimension) and Regime II (sparse high dimension).
- **real_data/**: Concrete compressive strength (Gamma regression) and Colon microarray classification (Logistic Lasso).

## Dependencies
- `CVXR`, `glmnet`, `MASS`, `readxl`, `httr`
